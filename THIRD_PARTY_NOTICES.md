# Frontend component and asset notices

## Skiper UI — free CssLink

The animated underline pattern in `.text-link` adapts Link001 in Skiper UI's free CssLink by gxuri. [Skiper UI](https://skiper-ui.com) · [Component](https://skiper-ui.com/v1/skiper40) · [Source](https://skiper-ui.com/r/skiper40.json).

Published terms permit personal and commercial use and modification, and require attribution for free usage. This notice provides attribution. No Pro components are included.

## Vengeance UI — perspective grid and spotlight navigation

Iteration 2 also adapts the [Spotlight Navbar](https://www.vengenceui.com/components/spotlight-navbar) pointer-position lighting pattern to the vertical AgentGate navigation rail. [Published source](https://raw.githubusercontent.com/Ashutoshx7/VengeanceUI/main/public/r/spotlight-navbar.json). Native requestAnimationFrame and CSS variables replace React state and Framer Motion; the MIT license below covers both adaptations.

The hero's CSS grid adapts the projection and fading pattern of PerspectiveGrid by Ashutoshx7. [Project](https://github.com/Ashutoshx7/VengeanceUI) · [Component](https://www.vengenceui.com/components/perspective-grid).
